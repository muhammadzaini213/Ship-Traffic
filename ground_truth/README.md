# Kebenaran dasar

Lakukan pelabelan manual untuk sekitar 100–200 objek kapal pada citra yang dipilih. Simpan hasil sebagai `ground_truth/ground_truth.csv` dengan kolom:

- `id`
- `date`
- `row`
- `col`
- `label`
- `labeler`
- `second_labeler`

Kolom `second_labeler` digunakan untuk pemeriksaan silang oleh pelabel kedua. Jelaskan di proposal atau dokumen ini: aturan batas objek, sumber citra yang dilabeli, proses resolusi perbedaan, dan pembatasan interpretasi visual.
